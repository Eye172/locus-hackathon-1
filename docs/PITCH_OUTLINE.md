# Презентация — 8 слайдов (PDF)

1. **CampusLens** — «Покажите университет таким, каким его увидит студент». Планета на фоне космоса, команда, кейс 1.
2. **Проблема** — рекламные страницы против реальности; фото разбросаны, устарели, чужие; кейс штрафует за подделку.
3. **Решение** — название → перелёт → профиль за 25 секунд: 8 категорий, источник и уверенность у каждого фото, честные пустые состояния.
4. **Демонстрация** — 3 скриншота: планета/перелёт, альбомы с полосами достоверности, паспорт фото с сигналами.
5. **Технология** — агенты Scout → Inspector → Curator → Judge → Writer; проверка по построению (сайт, Commons depicts, полигон OSM); CLIP на CPU; формула уверенности; стек.
6. **Преимущества** — не «поиск картинок»: доказуемость, отклонённые видны, режим жюри, 3D-кампус, климат и город из открытых данных, без ключей и оплаты; любой вуз мира.
7. **Команда** — роли и вклад.
8. **Развитие** — прогрев всех вузов ЦА, внешние коллекторы через `/api/ingest`, Street View/Mapillary обход, метрика точности как публичный бенчмарк, партнёрство с LOCUS.

Стиль: белый фон, синий акцент, чёрный текст, топографический узор; по одной мысли на слайд; цифры моноширинным.
