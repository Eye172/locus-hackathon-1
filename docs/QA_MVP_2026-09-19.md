# Проверка опубликованного MVP — 19 сентября 2026

## Второй проход: ошибки, импорт и публикация

Дополнительные исправления:

- Неизвестный адрес раньше давал пустой экран. Теперь появляется «Страница не найдена» со ссылкой на главную; подтверждено в браузере.
- Импорт проверяет структуру всех разделов до записи, принимает только ключи CampusLense, объединяет вузы с текущими данными и восстанавливает уже записанные ключи при ошибке записи. Повреждённые записи в localStorage больше не ломают страницу. Язык сохраняется и переносится в правильном формате.
- Через реальный выбор файла в браузере проверены повреждённый и корректный JSON. Первый отклонён с сообщением; второй прочитан, страница перезагрузилась, оба ранее сохранённых вуза и избранное остались.
- Экспорт подготавливает JSON, добавляет ссылку скачивания в DOM и освобождает object URL. Сообщение объясняет, что делать, если встроенный браузер не начал скачивание. Полный цикл сериализации/восстановления проверен автоматически; получение файла встроенным браузером по-прежнему не подтверждено.
- При обрыве SSE профиля в состоянии CONNECTING вызывается обработчик ошибки. Чат обнаруживает конец потока без завершающего события. Эти сетевые отказы проверены имитацией транспорта в тестах, без отключения сети пользователя.
- Поиск отбрасывает устаревшие ответы после изменения/очистки запроса, показывает сетевую ошибку и завершает индикатор загрузки. Быстрая смена MIT → Nazarbayev и очистка Backspace проверены в браузере.
- Ошибка профиля больше не соседствует с индикатором продолжающейся сборки; сбой сброса настроек обрабатывается.
- На ширине 360 px поле поиска и кнопки экспорта/импорта помещаются; горизонтального переполнения не обнаружено.
- Обычный rolling deploy завершился в CLI, но HTTP продолжал отдавать старый frontend. После `modal deploy --strategy recreate deploy/modal_app.py` сервер выдал новую сборку. В инструкции добавлены recreate и проверка совпадения опубликованного index.html с локальным.

Проверки второго прохода: **7 frontend-тестов + 2 backend-теста — успешно**; **12 HTTP-проверок опубликованного сайта — успешно**; TypeScript и production build — успешно. Настройки поиска (сохранение, валидация, сброс) протестированы API-тестом в отдельном временном файле, без изменения общих настроек сайта. `npm run lint` завершился с кодом 0, но в проекте остаются существующие предупреждения React/hooks; это не чистый lint-отчёт. После повторной браузерной проверки журнал ошибок пуст.

Повторяемые команды: `npm test` в frontend, `python -m unittest discover -s tests -v` в backend, `python deploy/smoke_check.py` в корне. Скрипт HTTP-проверки не запускает сборки профилей и не меняет данные.

## Исправлено и опубликовано

1. Старый кэш выдавал автомобильные 12 минут за время ходьбы на 7,4 км. При запуске приложения старые context/map3d записи получают оценку ходьбы, сохраняя остальные данные и дату кэша. Новые записи маркируются; UI явно обозначает оценку. На опубликованном сайте подтверждено: 111 минут пешком, 12 минут на машине.
2. Переведены основная навигация, возврат из профиля и кнопка «Вся планета».
3. Кнопка избранного получает правильную подпись и aria-pressed после переключения.
4. Строки тем поиска перестроены для узкого экрана; повторный скриншот 390×844 подтвердил отсутствие наложения.

Проверки кода: `npm run build` (TypeScript + production build) — успешно; `python -m unittest discover -s tests -v` — успешно. Тест миграции проверяет обе группы кэша, повторный запуск, сохранение других полей и даты. `git diff --check` — успешно. Исправления развёрнуты командой `modal deploy deploy/modal_app.py` и проверены в браузере. В доступном журнале браузера после обновления ошибок JavaScript не обнаружено.

## Ограничения и оставшиеся замечания

- Экспорт: кнопка нажата, но браузерный инструмент не получил событие скачивания. Работу скачивания файла в этом браузере подтвердить не удалось; это не доказательство ошибки приложения. Импорт файла не проверен.
- Полная локализация ещё не завершена: в разделах «Мои вузы» и настроек остаётся русский текст. Исправление этого прохода охватывает основную навигацию.
- Глобальное сохранение/сброс настроек поиска и жалоба «Не этот вуз» не отправлялись: они меняют общие данные сервиса. Проверены загрузка и раскрытие настроек.
- Flickr отключён из-за отсутствующего ключа. Остальные проверенные сценарии работают без него; доступность внешних сервисов может меняться.
- Проверен интерфейс и выполнение ИИ-запросов; фактическая точность всех автоматически собранных описаний, цен и фотографий отдельно не аудировалась.
- Проверка выполнена в одном браузере, включая изменение ширины окна. Реальные iOS/Android, другие браузеры, нагрузка и работа офлайн не проверялись.

Тестовые пункты плана удалены. Ранее сохранённый MIT оставлен без изменений; NU и одно избранное фото сохранены как результат проверки. Размер окна и русский язык восстановлены, главная оставлена открытой.
