# CampusLense — дизайн-спецификация

Для людей и для ИИ-агентов, которые правят фронтенд. Если правка расходится с этим файлом, неправа правка. Токены
живут в `frontend/src/index.css` (`@theme`, `@layer components`), знак — в `frontend/src/components/Logo.tsx`
и `docs/design/logo/`.

## 1. Суть

Богатый минимализм: белая бумага, чёрный текст, один синий акцент, фотографии — главный цвет страницы.
Дорого выглядит не декор, а порядок: одна сетка, три размера скругления, ровные отступы, крупная типографика
заголовков, тишина вокруг. Каждый элемент либо несёт факт, либо ведёт к нему.

1. **Сначала вуз, потом механизм.** Над сгибом: имя, ключевые факты, лучшие фото, одна строка о проверке.
   Этапы, источники, пороги и журнал — во вкладке «Проверка», не в шапке.
2. **Честность видна, но не кричит.** Процент уверенности — мелкий серый текст с цветной точкой, а не зелёная
   полоса под каждым фото. Пустая тема — одна фраза, а не пустая карточка.
3. **Одно действие главное.** На экране одна чёрная кнопка (`btn-primary`). Остальные — контурные.
4. **Текст вместо иконок.** Иконка рядом с подписью, а не вместо неё. Непонятная иконка без подписи — ошибка.

## 2. Токены

```yaml
color:
  ink: "#0B0D12"        # текст, главная кнопка, активная вкладка, знак
  ink-2: "#3B414E"      # основной текст абзацев
  muted: "#6B7180"      # подписи, метки, счётчики
  faint: "#A0A5B0"      # третичное: сноски, подсказки
  line: "#E9EBEF"       # волосяные линии
  line-2: "#D6DAE1"     # границы полей и контурных кнопок
  soft: "#F4F5F7"       # подложка плиток фото, hover, сегмент-контрол
  brand: "#1D4ED8"      # только ссылки при наведении, фокус, выделение текста
  verified / likely / unverified: "#15803D" / "#B45309" / "#B91C1C"   # только точки и числа, не заливки
type:
  sans: Onest 400/500/600      # весь интерфейс; кириллица и казахские буквы есть
  display: Onest 600, трекинг −3 %  # имя вуза и заголовки страниц (h1); засечек в интерфейсе нет
  mono: JetBrains Mono         # только хэши, журнал, код (.code); казахских букв в нём нет
  scale: 12 · 13 · 13.5 · 14.5 · 15 · 16 · 17 · 20 · 26 · 36 · 44
  body: 15/1.55, абзацы описания 17/1.65, ширина строки ≤ 65–70ch
  h1: Onest 600 44 (32 на телефоне), трекинг −3 %
  h2 разделов: Onest 600 20, трекинг −1.5 %
  метки над значениями: 13 muted; значения 16–17 medium
  numbers: lining; tabular (.tnum) только в столбцах
space: 4 · 8 · 12 · 16 · 24 · 32 · 40 · 48 · 56 · 64   # между разделами 48–56, внутри раздела 12–16
radius: 8 (кнопки, поля, фото в сетке) · 12 (карточки, модальные окна) · 16 (галерея в шапке) · full (фильтры)
elevation: линии, а не тени. Тень — только у плавающего: меню, модальное окно, кнопка поверх фото.
icons: lucide, stroke 1.75, 15–17 px рядом с текстом 13–15 px
motion: 150–200 мс, только opacity/transform/filter; hover на фото — затемнение brightness 0.9, без зума
```

## 3. Компоненты

| Класс | Где | Правило |
|---|---|---|
| `btn-primary` | «3D-карта кампуса», «Открыть источник» | один на экран |
| `btn-ghost` | Сохранить, Сравнить, Обновить | с подписью |
| `btn-icon` | Поделиться, Пересобрать | только общеизвестные иконки и всегда `title`/`aria-label` |
| `tab` / `tab-active` | вкладки профиля | текст + 2 px чёрная черта; счётчик — серый, без плашки |
| `filter` | категории фото | пилюля, активная чёрная, счётчик внутри |
| `seg` | вид: Альбомы / Сетка / Брошюра и реальность | 2–4 варианта одного набора данных |
| `btn-text` | «Показать ещё 7» | без рамки, со стрелкой |
| Факты | шапка профиля, «Что есть на кампусе» | метка 13 muted сверху, значение 16 снизу, без иконок и рамок |
| `h-sec` (+ `<small>`) | заголовок раздела на любой странице | Onest 600 20; пояснение — 13 muted в той же строке. Никаких caps-заголовков |
| `lbl` / `val` / `val-lg` | пара «метка — значение» (Город, факты) | метка сверху, число снизу; без рамок и черты слева |
| `row-link` | списки (недавние профили, «что рядом») | строка с волосяной линией сверху вместо карточки |
| Кнопка на тёмном (планета) | поиск, «Открыть профиль» | белая с чёрным текстом, без свечения |
| Плитка фото | везде | 4:3, скругление 8, подпись: источник слева, «• 94 %» справа; категория — только в смешанной сетке |

Состояния обязательны у каждого блока с данными: загрузка (скелет `shimmer` в реальных размерах), пусто (одна
фраза, что искали), ошибка (что случилось и куда нажать).

## 4. Страница вуза

```
Хлебные крошки: Планета / Страна / Город
Имя вуза (Onest 600 44) · подзаголовок        [3D-карта кампуса] [Сохранить] [Сравнить] [↗] [⟳]
Город · Основан · Студентов · Сайт           — ряд фактов, без рамок
Галерея: 1 большое + 4 малых, «Все N фото»   — лучший вид кампуса первым, без постеров и текста на кадре
✓ 210 из 310 фото подтверждены … Как проверяли       Собрано за 23,9 с · 23 источника
────────────────────────── sticky ──────────────────────────
Обзор · Фото 310 · Кампус · Город · Климат · Проверка
```

- **Обзор** — «О вузе» (текст со сносками), «Какой это вуз» по темам (сетка 4 × 2, остальное по кнопке);
  справа узкая колонка: «Вокруг кампуса», «Фото по разделам», соцсети, план визита.
- **Фото** — фильтры категорий, вид (альбомы / сетка / брошюра и реальность), только подтверждённые, за 3 года, год.
- **Кампус** — справка «Что есть на кампусе» по текстам из сети + прогулка (грузится по кнопке).
- **Город**, **Климат** — как есть.
- **Проверка** — числа (подтверждено / вероятно / отклонено / время), как считается уверенность, фото по
  разделам, этапы, источники, отклонённые с причинами, «Что искали», «Технические детали» (журнал, JSON).

Вкладок не больше шести. Старые адреса `?tab=collage|about|walk|bvr|timeline|rejected|judge` ведут в новые.

## 5. Нельзя

- Градиенты, свечение, стекло с тенью, фиолетовый, градиентный текст.
- Пастельные плашки-чипы для статусов («хорошо» на зелёном фоне) — вместо них точка + слово.
- Цветная полоса по левому краю цитаты или карточки.
- Карточка в карточке; рамка у каждого блока; одинаковые карточки с иконкой сверху.
- Эмодзи в интерфейсе (флаги стран на Windows превращаются в буквы).
- Uppercase-метки с трекингом везде; допустимы только `caps` 11 px в плотных таблицах.
- Моноширинный шрифт для обычных чисел.
- Зум фото при наведении, анимации дольше 300 мс, bounce.
- Иконка без подписи, если это не «поделиться», «закрыть», «назад», «обновить».
- Второй акцентный цвет. Синий — не фон и не иконки.

## 6. Знак

Линза с портиком, два начертания: сплошное (основное, портик вырезан из линзы: фронтон, балка под ним, колонны,
ступень) и контурное.
Один цвет — цвет текста. Знак + «CampusLense» (Onest 600, −2 %), знак на 2 px ниже середины строки.
Файлы: `docs/design/logo/` (лист построения `index.html`, `sheet.png`), `frontend/public/logo/`, фавикон
`frontend/public/favicon.svg` (сам переключается на белый в тёмной теме браузера).

## 7. Проверка перед коммитом

1. Скриншот 1440 и 390 px: нет горизонтальной прокрутки (`scrollWidth === innerWidth`), ничего не обрезано.
2. На экране одна чёрная кнопка; у каждой иконки есть подпись или `aria-label`.
3. Все цвета — из токенов; новых hex в JSX нет (кроме карт и графиков).
4. Пустое, загрузка, ошибка — у каждого нового блока.
5. Текст на казахском не выпадает в запасной шрифт.

Источники: Refactoring UI (шкалы, трекинг, серые), Vercel Web Interface Guidelines (цифры, тени, цели нажатия),
NN/g — tabs used right, progressive disclosure, in-page links; Baymard — горизонтальные вкладки; impeccable.style/slop
(признаки «сгенерированного» интерфейса); Google DESIGN.md (формат спецификации для агентов).
