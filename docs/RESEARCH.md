## Идея 1. Гео-якорь кампуса через OpenStreetMap — ✅

**Что проверяли.** Overpass API: поиск объекта по тегу `wikidata`, геометрия полигона, здания внутри.

**Результат.**
- `nwr["wikidata"="Q427677"]` → way 360167896, полигон КазНУ из 73 точек, bbox 43.2145–43.2266 / 76.9178–76.9280. Время ответа ~1.9 с.
- Здания внутри полигона (`map_to_area`): 16 общежитий (`building=dormitory`, с названиями «№15-ші студенттер үйі»), 13 учебных корпусов (`building=university`, с названиями факультетов), 1 библиотека (`amenity=library`), 1 стадион (`leisure=stadium`), 3 площадки (`pitch`), 2 кафе.
- Назарбаев Университет → way 424894683 (полигон есть). КБТУ → relation 3206854 (полигон есть).
- Остановки транспорта в радиусе 500 м от центра КазНУ: 0 в OSM (кампус большой, остановки по периметру дальше). Решение: считать в радиусе 800 м от bbox, показывать блок только при ненулевом результате.

**Решение.** Резолв полигона: (1) по `wikidata`-тегу, (2) `amenity=university` в радиусе 600 м от координат с совпадением названия, (3) fallback — круг 500 м и честная пометка «границы кампуса не найдены, используем радиус». Здания классифицируем по тегам: `dormitory→dormitory`, `library→library`, `stadium|pitch|sports_centre|fitness_centre|swimming_pool→sports`, `university→academic`, `cafe|canteen→student_life`.

**Риск.** Overpass бывает перегружен (получали пустой ответ при быстрых повторах). Мера: таймаут 8 с, один повтор через 1 с, зеркало `overpass.kumi.systems` как запасной хост.

## Идея 2. Wikidata как резолвер и «Вы имели в виду» — ⚠️

**Результат.**
- `wbsearchentities` «КазНУ» (ru) → Q427677 первым, далее шум (сериал «Каратель», польские деревни). «КБТУ» → Q1734762. «Nazarbayev University» → Q2783344. «Satbayev» → город, село, университет Q1513804 третьим. «МГУ» → Q13164.
- `wbgetentities` даёт: labels ru/en/kk, **алиасы на трёх языках** (КазГУ, КазНУ, ҚазҰУ, Al-Farabi University…), P31 (классы), P856 сайт (`farabi.university` — актуальный домен, старый `kaznu.kz` не отвечает), P373 категория Commons, P131 город (Q35493 Алматы), P17 страна, P18 фото, P571 год основания, P2196 число студентов, sitelinks ru/en/kk.
- **P625 (координаты) у КазНУ отсутствуют.** Координаты есть в Wikipedia REST summary (43.225, 76.921) и в центре OSM-полигона.
- SPARQL-фильтр `P31/P279* Q3918` работает, но занимает **9.2 с** — в live-пайплайн не годится.
- Полнотекстовый поиск Wikidata (`list=search`) для опечаток бесполезен: на «универ алматы» возвращает Оксфорд и Гарвард. Nominatim на «универ алматы» — пусто.

**Решение.**
1. Офлайн-индекс университетов (скрипт `scripts/build_university_index.py`, SPARQL по странам: Центральная Азия с замыканием подклассов + ~40 стран по прямому P31) → `data/universities.json`; fuzzy-поиск через `rapidfuzz` по labels+aliases на трёх языках. Даёт устойчивость к опечаткам и мгновенный ответ.
2. Параллельно `wbsearchentities` на трёх языках для вузов вне индекса; фильтр кандидатов: P31 из известного набора классов ИЛИ описание содержит `университет|university|университеті|institute|институт|college|академия|academy`.
3. Экран «Вы имели в виду» с городом, страной и логотипом; при нуле кандидатов — честное состояние «не нашли, попробуйте официальное название».
4. Цепочка координат: P625 → центр OSM-полигона → Wikipedia summary → Nominatim.

## Идея 4. Краулер официального сайта — ⚠️

**Результат.**
- `nu.edu.kz`: 200, 0.37 с, 36 `<img>`, 83 ссылки с ключевыми словами (about/…).
- `kbtu.edu.kz`: 200, 116 `<img>`, есть страница общежития `/kz/studentterge/zhatakhkhana` → 20 изображений, среди них реальные фото `jastar_001.JPG`.
- `enu.kz`: 200, `/kz/photo-gallery` с подписями на казахском, og:image.
- `farabi.university`: 200, 31 `<img>`, страница `/students/kampus?lang=ru` → 16 изображений, но в основном **иконки PNG** из `/media/icons/`.
- **SSL:** `farabi.university` и `kbtu.edu.kz` не отдают полную цепочку сертификатов → Python `httpx` падает с `CERTIFICATE_VERIFY_FAILED`, curl и браузеры работают. Повтор с `verify=False` даёт 200 и валидный JPEG.

**Решение.** Главная + до 4 подстраниц по ключевым словам на трёх языках (`campus|kampus|кампус|dorm|hostel|zhatak|жатақ|общеж|student|студен|gallery|галере|photo|foto|life`). Кандидаты: `og:image`, `<img src|data-src|srcset>`, CSS `url(...)`. Отсев по URL (`icon|logo|sprite|banner|flag|avatar|.svg|.gif`) и по размеру после загрузки (min side ≥ 300 px). При ошибке SSL — один повтор без проверки сертификата (только для GET картинок и HTML, фиксируется в логах и README как ограничение).

## Идея 5. Wikimedia Commons — ✅

**Результат.**
- Категория `Al-Farabi Kazakh National University`: 12 файлов + подкатегории (alumni, персоналии — их не берём). Среди файлов есть портреты («Ж.Миллионов.jpg») → нужен фильтр мусора.
- Категория `Nazarbayev University`: 31 файл, много логотипов/голограмм/делегаций → фильтр мусора обязателен.
- Structured data: `haswbstatement:P180=Q427677` («depicts») → 2 файла. Самый сильный сигнал принадлежности.
- `imageinfo` + `extmetadata`: `DateTimeOriginal` (2016-04-03 12:15), `Artist`, `LicenseShortName` (CC BY-SA 4.0 / CC BY 2.0), `ImageDescription`, **`GPSLatitude/GPSLongitude`** (43.226427, 76.921847 — внутри полигона КазНУ), `Credit` (в одном случае ссылка на Flickr-оригинал — бонусный источник). `thumburl` отдаёт готовый превью-URL.
- Геопоиск (`list=geosearch`, 800 м): много шума (грибы и клещи из соседнего ботсада) — использовать только с фильтром по полигону + CLIP.
- Изображения статей Википедии (`prop=images`): даёт 2 фото + SVG-флаги/иконки → фильтр по расширению.
- Загрузка превью: `thumb.wikimedia.org` требует User-Agent с контактом; 200 OK, 200 КБ за ~0.3 с.

**Решение.** Четыре под-источника: категория (без подкатегорий), depicts, изображения статей ru/en/kk-Википедии, геопоиск в bbox полигона. Метаданные пакетно через один `imageinfo` на 50 файлов.

## Идея 6. Mapillary — 📄

**Документация (проверена):** `GET https://graph.mapillary.com/images?access_token=…&fields=id,thumb_1024_url,captured_at,geometry,is_pano,sequence&bbox=left,bottom,right,top`. Параметр `fields` обязателен. **Ограничение: площадь bbox < 0.01 кв. градуса** (bbox КазНУ ≈ 0.00012 — укладывается). Лимит 60 000 запросов/мин на приложение. Клиентский токен выдаётся бесплатно в `mapillary.com/dashboard/developers` без OAuth.

**Решение.** Модуль включается при наличии `MAPILLARY_TOKEN`. Без токена этап помечается «источник отключён: нет ключа». Лента «Прогулка» показывается при ≥ 5 снимках.

## Идея 7. Flickr и Google Places — 📄

**Flickr.** Документация не открылась из этой сети (ECONNRESET), параметры известны и стабильны много лет: `flickr.photos.search` с `api_key`, `bbox=minlon,minlat,maxlon,maxlat`, `has_geo=1`, `extras=date_taken,owner_name,license,geo,url_m,url_c,url_l,tags`, `per_page≤500`, `format=json&nojsoncallback=1`. Ключ выдаётся мгновенно (некоммерческий). Проверить при получении ключа.

**Google Places (New), проверено по документации:** Text Search с `X-Goog-FieldMask: places.id,places.photos,places.displayName` → `photos[].name` и `authorAttributions`; медиа по `https://places.googleapis.com/v1/{name}/media?maxWidthPx=800&key=…`; до 10 фото на место; имена фото нельзя кэшировать. Нужен биллинг.

**Решение.** Оба — отключаемые модули по ключам. Пайплайн полноценно работает на бесплатных источниках (сайт, Commons, Википедия, OSM), что и есть базовая поставка.

## Идея 8. Кросс-источниковая provenance — ✅ (данные есть)

pHash из `imagehash` установлен. Пример из исследования: файл на Commons с `Credit` → ссылка на Flickr-оригинал, т.е. одно фото уже подтверждено двумя источниками. Реализация: одинаковый pHash (Hamming ≤ 8) у кандидатов из разных источников → объединение, `sources_count += 1`, бонус к уверенности.

## Идеи 9–11. Дедуп, фильтр мусора, категоризация (CLIP) — ✅

**Бенчмарк CLIP ViT-B/32 (laion2b_s34b_b79k), CPU, 16 потоков:** загрузка модели 31.9 с при первом скачивании (из кэша ~3–5 с), **32 изображения → 1.5 с**, кодирование текста 0.16 с. Вывод: 80 изображений ≈ 4 с на CPU, GPU не нужен, деплой на бесплатном CPU-хостинге возможен. Вес модели ~600 МБ, кэшируется.

**Решение.** Zero-shot по 8 категориям (по 2–4 промпта на категорию, усреднение эмбеддингов) + 8 классов мусора. Дедуп: pHash Hamming ≤ 8 → копия; косинус CLIP ≥ 0.93 → визуально похожие. Категория усиливается тегом здания OSM (если геометка в 40 м от здания) и ключевыми словами из подписи/URL на трёх языках.

Интерфейс показывает режим («LLM» или «шаблон»).
