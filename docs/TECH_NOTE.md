# Техническая справка CampusLens

## Модели и AI-компоненты

| Компонент | Модель / метод | Где исполняется | Назначение |
|---|---|---|---|
| Семантика и категории | CLIP ViT-B/32 (open_clip, веса laion2b_s34b_b79k) | сервер, CPU | zero-shot по 8 категориям и 8 классам мусора; эмбеддинги для поиска похожих |
| Дубли | SHA-1, pHash 8×8 (Hamming ≤ 8), dHash, косинус эмбеддингов ≥ 0.93 | сервер | копии и визуально похожие снимки |
| Судья (опц.) | Gemini 2.5 Flash vision или Claude (`claude-opus-5`) | API | второе мнение по фото с уверенностью 0.30–0.65, ≤ 10 на профиль, кэш по SHA-1 |
| Описание (опц.) | тот же LLM, JSON-схема с цитатами; без ключа — шаблон | API / сервер | 5–7 предложений, каждое с номером источника |
| Сравнение и чат (опц.) | тот же LLM; без ключа — правила | API / сервер | плюсы/минусы и ответы только по фактам двух профилей |
| Карты глубины | Depth Anything V2 Small (transformers, CPU) | сервер | параллакс «3D-фото»; пиксели не меняются |
| Поиск названия | rapidfuzz WRatio по 40 000 вариантов имён (ru/kk/en, транслитерация, города) + Wikidata API | сервер | устойчивость к опечаткам |

## Проверка результата

- Каждое фото несёт список сигналов с весами и итоговую уверенность (формула в `docs/ARCHITECTURE.md` §3).
- Кликабельный источник у каждого фото; отклонённые остаются видимыми с причиной.
- Режим жюри: этапы, тайминги, статусы источников, лог, JSON профиля, `GET /api/schema`.
- `scripts/eval.py` считает precision / recall / F1 верификации по ручной разметке `data/labels.json`.
- `scripts/smoke.py` прогоняет пайплайн без браузера.

## Безопасность и ограничения

- Секреты только в `.env`; в репозитории нет ключей. Google-ключ фронтенда ограничен по referrer.
- Никаких сгенерированных изображений в роли фото кампуса; катсцены (если будут) подписаны как анимация.
- SSL-fallback без проверки сертификата используется только для GET публичных страниц/картинок сайтов вузов с неполной цепочкой.
- Публичные API имеют лимиты: таймауты и деградация по источникам, кэш профилей/климата/контекста в SQLite.
- Персональные данные не собираются; localStorage хранит только предпочтения пользователя на его устройстве.
